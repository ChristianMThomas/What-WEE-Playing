# Home Page & Navigation

- Home page styled like the Wii menu with channels
- Each channel represents a different game (Bowling first, Just Dance next, others later)
- Clicking a channel: choose **Single Player** or **Multiplayer**
- Multiplayer: choose **Create Lobby** or **Join Lobby**
- The menu is driven with the phone as well as the mouse: point it at the screen and a hand cursor follows, A selects, B goes back (see `md/11`). The bar along the bottom pairs a phone, next to Settings, so the remote can be picked up before entering a channel
